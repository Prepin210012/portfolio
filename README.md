# Alex — Portfolio Website

This website is a personal portfolio designed to present a blend of analytical thinking, technical ability, and economic understanding. It reflects a focus on mathematics, computing, finance, and systems thinking, with an emphasis on clarity, structure, and precision.

The site highlights key areas of interest including game theory, market dynamics, collective welfare, and computational problem-solving. It also provides space for written work, allowing ideas to be explored and communicated over time.

The overall design aims to feel sharp, intentional, and professional — drawing inspiration from quantitative research, engineering systems, and financial interfaces rather than generic portfolio styles.

This project serves as both a personal showcase and a foundation that can evolve alongside future work, research, and ideas.
